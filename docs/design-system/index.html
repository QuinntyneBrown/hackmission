How to use

  • Link tokens/tokens.css then assets/components.css; use the documented classes and attributes.
  • Never write a colour, size or duration: add a token to tokens.css and regenerate tokens.json (scripts/tokens_to_json.py).
  • Consume tokens/tokens.json (DTCG) for platform constants; contrast-pairs.json lists every pairing to keep passing.
  • In the Angular app, every component here is implemented once in frontend/projects/components/ and reused (see AGENTS.md).
  • Toggle the theme with the button or t; ?theme=dark forces it.
