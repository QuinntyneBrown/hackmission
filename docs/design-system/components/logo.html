Logo

Code braces framing a cross — code in service of the mission — and the HackMission wordmark.

Overview

The mark is two code braces { } framing a gold cross. The lockup sets the mark beside the wordmark: Hack in Manrope 800, Mission in Manrope 500, tracked −0.035em, one word. The braces take the text colour; the cross is always gold.

Anatomy

  1. Braces5-unit stroke, round caps, currentColor.
  2. CrossGold --color-brand-mark, rounded 1.5.
  3. WordmarkHack 800 + Mission 500, gap 0.36em.

Responsive behaviour

  • The header lockup drops to .logo--sm below 400px so it fits beside the CTA.
  • Minimum mark size 16px; minimum lockup height 20px.

Theming

Only the cross is a fixed colour. Everything else inherits, so one SVG works on paper, ink and gold (on the gold disc the cross becomes ink via --color-fg-on-gold).

Accessibility

Role and pattern

An <a> with aria-label="HackMission home"; the SVG is aria-hidden. The wordmark text is real text, so it is also readable.

Content

  • Always one word, capital H and M: HackMission. Never “Hack Mission”, “HACKMISSION” or “hackmission” in running text.
  • Do not add a tagline inside the lockup.
