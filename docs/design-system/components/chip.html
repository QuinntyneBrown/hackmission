Chip

A toggle or a removable value in a compact pill.

Overview

Filter chips toggle a filter (city, format); input chips hold a chosen value with a remove button. Static chips are badges.

Anatomy

  1. ChipPressed: accent-subtle background, accent text.

Variants

Montréal
Filter chips (toggle) and an input chip (removable).

Sizes

sm 32px (default) · md 40px.

States

VariantDefaultHoverFocusPressedDisabled
Filter chip

Responsive behaviour

  • Chips wrap in a .cluster; the row scrolls horizontally in toolbars.

Theming

Pressed uses accent-subtle + accent text.

Accessibility

Role and pattern

Filter chips are buttons with aria-pressed; input chips are text with a labelled remove button.

Keyboard

KeyAction
TabThrough chips and remove buttons.
Space, EnterToggles / removes.
BackspaceIn a combobox, removes the last chip.

Focus

Standard ring.

Labelling

Remove buttons say what they remove ("Remove Montréal").

Contrast

Pressed text
Chip border

Motion

None.

Touch

32px tall, ≥ 44px wide; 8px gaps.

Content

  • One or two words.
