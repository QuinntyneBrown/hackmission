Container, grid & stack

The four layout primitives every page is built from.

Overview

.container caps width and adds the page margin; .grid lays out columns from the layout tokens; .stack spaces children vertically; .cluster wraps items on a row. The marketing sections, the numbers row, steps and schedule are all grids inside containers.

Anatomy

  1. ContainerMax --layout-container-max, margin --layout-margin.
  2. Grid--layout-columns × --layout-gutter.

Sizes

.stack--sm (8px) · .stack (16px) · .stack--lg (32px); gutters follow --layout-gutter.

States

Not applicable: Layout primitives have no interactive states.

Responsive behaviour

  • Columns: 4 < 768px, 8 < 1024px, 12 above; gutters 16 / 24 / 32px; margins 16 / 32 / 48px.
  • Sections use .section--roomy (96px, fluid to 136px on desktop) on the marketing page.

Theming

No colour; spacing tokens only.
