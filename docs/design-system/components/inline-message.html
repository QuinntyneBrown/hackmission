Inline message

The small line under a field: a hint, an error, or a success note.

Overview

Inline messages belong to one control: help text, an error, a saved indicator. They are linked with aria-describedby so they are read with the field.

Anatomy

  1. Hint
  2. Error⚠ + sentence.
  3. Inline statusIcon + word.

Variants

Error: add the end of your email address.
