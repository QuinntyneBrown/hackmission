Overview

Steps explain a process in three numbered moves. The numbers sit in braces ({ 01 }) in the mono face, echoing the logo. This is content, not a progress indicator; a form wizard uses the stepper in components.css.

Anatomy

  1. NumberMono, gold, in braces.
  2. TitleExtrabold, 20–24px.
  3. LineMuted, max 18ch.

Variants

  1. { 01 }

    Meet the mission

    Partners pitch.

  2. { 02 }

    Build

    Mentors alongside.

  3. { 03 }

    Hand it over

    Demo and deliver.

Three steps.
