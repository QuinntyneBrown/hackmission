Skeleton

Grey shapes in the layout's place while content loads, so nothing jumps.

Overview

Skeletons hold the layout while a list or card loads. The marketing page is prerendered and needs none; organiser tables and cards use them.

Anatomy

  1. Title bar
  2. Text bars

Variants

Text, title, circle, rect.
Composed card.

Sizes

Not applicable: Shapes match the content they replace.

States

Shimmer runs while aria-busy.

Responsive behaviour

  • Skeleton widths are percentages so they match the final layout at every width.

Theming

Subtle background with a shimmer to subtle-hover.

Accessibility

Role and pattern

aria-hidden shapes inside a container with aria-busy="true"; a visually hidden “Loading…” is announced once.

Keyboard

KeyAction
—Not interactive.

Focus

None.

Labelling

The container says what loads.

Contrast

Shape on surface (decorative)

Motion

Shimmer over --duration-deliberate; static under reduced motion.

Touch

—

Content

  • Match line count to the real content; never more than five lines.

  <span class="visually-hidden">Loading events</span>

</div>
