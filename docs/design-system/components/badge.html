Badge

Status in a word: a tinted pill, a solid count, or the hero's next-date pill.

Overview

Badges state a status (Open, Pending, Confirmed) with colour and a word. Counts are solid pills with an aria-label. The hero's next-date pill is a badge variant with a gold dot.

Anatomy

  1. DotGold; aria-hidden.
  2. TextBold, --font-size-sm, 1px hero border.

Responsive behaviour

  • The next-date pill wraps onto two lines below 400px; the dot stays on the first line.

Theming

Status tints use the --color-*-bg/fg pairs; in dark they become deep tints with light text. The pill border uses --color-border-hero.

Accessibility

Role and pattern

Plain <span>; counts add aria-label with meaning ("4 upcoming"). Colour is paired with the word.

Content

  • One word, sentence case: "Confirmed", "Pending".
  • Pill text: "Next: Toronto · 6–7 Feb 2027 · registration opens 15 Dec"; when no date is announced: "Next date announced soon — be first to know".
