Sidebar navigation

Grouped links with badges for the organiser tools; a drawer below 1024px.

Overview

The public site has no sidebar; the organiser app (events, subscribers, settings) will. Groups are labelled, the current page is marked, counts are badges with meaning.

Anatomy

  1. Nav linkIcon + label, 40px.
  2. BadgeCount with aria-label.
  3. Group labelOverline.

Responsive behaviour

  • ≥ 1024px: fixed column beside the content (.sidebar-layout).
  • < 1024px: hidden behind a menu button in the top bar; opens as a left drawer with the page inert.

Theming

Surface background, subtle hover, accent-subtle current row with accent text.

Accessibility

Role and pattern

<nav aria-label> of links; aria-current="page" on the current one. Collapsible groups use <details>.

Keyboard

KeyAction
TabThrough links in order.
EnterFollows.

Focus

Opening the drawer moves focus to the first link; closing returns it to the menu button.

Labelling

Badges have aria-label ("4 upcoming").

Link

Motion

Drawer slides over --duration-slow; none under reduced motion.

Touch

Rows 40px tall, full width.

Content

  • Labels are plural nouns for lists ("Events"), singular for pages ("Settings").
