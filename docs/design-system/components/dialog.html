A focused task over the page: watch the intro, confirm an unsubscribe.

Overview

A dialog interrupts for one task. The site has one: the intro video, on an ink panel. Destructive confirmations (unsubscribe) use the danger variant. Use a page, not a dialog, for anything longer than a short form; use a pattern decision table when unsure.

Anatomy

  1. Icon (danger/info)
  2. Title + descriptionaria-labelledby / aria-describedby.
  3. CloseGhost icon button; Esc does the same.
  4. FooterSafe action first and focused; destructive last.

Responsive behaviour

  • < 640px the panel becomes a bottom sheet: full width, --radius-xl top corners, footer sticky.
  • The video panel keeps a 16:9 player and the transcript scrolls inside the body.

Theming

Panel on --color-bg-surface-raised with --shadow-4 and the backdrop scrim; the video variant switches to --color-bg-hero-deep with hero text tokens so the player sits on ink in both themes.

Accessibility

Role and pattern

APG Modal dialog: role="dialog" aria-modal="true", aria-labelledby, aria-describedby; the page behind gets inert; focus is trapped.

Keyboard

KeyAction
Tab / Shift+TabCycles inside the dialog.
EscCloses (also when busy, cancelling nothing already sent).
EnterActivates the focused button; never the destructive one by default.

Focus

Opens on the safe button (autofocus) or the first field; the video dialog opens on the close button so the player's own controls come next. Closing returns focus to the trigger (“Watch the intro”).

Labelling

Title is the name; description is the first paragraph. The close button is labelled “Close video” / “Close”.

Motion

Fades and rises 8px over --duration-slow with --ease-enter; instant under reduced motion. The video never autoplays with sound; captions are off by default and available via CC.

Touch

Footer buttons ≥ 44px on phones; the sheet's close button sits within thumb reach.

Content

  • Titles are questions for confirmations ("Unsubscribe amara…?") and titles for content ("HackMission in 20 seconds").
  • Buttons name the outcome: "Keep me subscribed" / "Unsubscribe".
  • Never "Are you sure?".
