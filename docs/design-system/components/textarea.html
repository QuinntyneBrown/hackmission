Overview

A textarea collects several lines: a message to the organisers, a project description. Not on the marketing site yet; core set for the contact and registration forms.

Anatomy

  1. Label
  2. TextareaMin 2 rows, vertical resize only.
  3. CounterLive, muted; turns danger at the limit.

Responsive behaviour

  • Resize handle is vertical only so the layout cannot break.

Content

  • Counters count down only when a hard limit exists.
