Switch

A setting that takes effect the moment it is flipped.

Overview

A switch turns a setting on or off with immediate effect (no Save button): email reminders in a subscriber's preferences. Use a checkbox when the change is submitted with a form.

Anatomy

  1. Track + thumb44×24px; accent track when on.
  2. LabelDescribes the setting, not the action.

Variants

Label right (default). Put the label left only in dense settings tables.

Sizes

Not applicable: One size: 44×24px track.

States

VariantDefaultHoverFocusDisabled
On
Off

Responsive behaviour

  • Row is 40px; label wraps while the switch stays right-aligned in settings lists.

Theming

On-track uses --color-accent; off-track --color-border-strong so the state is visible without colour (position + 3:1 edge).

Accessibility

Role and pattern

<input type="checkbox" role="switch"> inside a label. APG: Switch.

Keyboard

KeyAction
TabMoves to the switch.
SpaceToggles; the change applies immediately.

Focus

Ring around the track.

Labelling

The label names the setting ("Event reminders"); the state is announced as on/off.

Contrast

Thumb on track (on)
Off track edge

Motion

Thumb slides over --duration-fast; instant under reduced motion.

Touch

44×24px track inside a 40px row.

Content

  • Label the setting, not the action: "Event reminders", not "Turn on reminders".
  • Say when the change takes effect if it is not immediate.
