Error page

When a whole page cannot be shown: keep the shell, explain, offer one way out.

Overview

Error pages keep the header and footer so the site stays navigable. The 404 is the only one mocked; 403, 500, offline and maintenance follow the same shape with their own code and copy. The expired-link page (pages/confirm/error) is this pattern without a code.

Anatomy

  1. Code in bracesThe brand’s { } motif.
  2. Title + explanation
  3. One action

Responsive behaviour

  • The simple page is 36rem wide and centred; copy wraps at 28rem.
  • The action is full width below 640px.

Theming

Canvas colours; the code uses --color-brand-highlight in the mono face.

Accessibility

Role and pattern

A normal page with one <h1>, the header and footer landmarks, and a link or button.

Keyboard

KeyAction
TabSkip link → header → action → footer.

Focus

Standard.

Labelling

The title says what happened; the code is decoration (in braces).

Content

  • Title in the site's voice: "This page wandered off". Body: why, then where to go.
  • 500 pages include a short reference id a person can quote.
  • Never "Oops!".
