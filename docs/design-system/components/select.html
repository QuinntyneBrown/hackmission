Overview

A native select picks one option from a short list: the city for a registration, the format of an event. Native first; a custom listbox only when the options need rich content.

Anatomy

  1. Label
  2. Value / placeholder optionAn empty first option that reads as a prompt.
  3. ChevronInline SVG mask, inherits text colour.

Variants

Native select with a placeholder option; sizes follow the text field.

Sizes

Small, medium, large.

States

VariantDefaultHoverFocusDisabledInvalid
Select

Responsive behaviour

  • Full width; on phones the OS picker opens, which is why native is preferred.

Theming

Text-field tokens; the chevron uses currentColor so it follows the theme.

Accessibility

Role and pattern

Native <select> with a label.

Keyboard

KeyAction
TabMoves to the select.
Space, Alt+↓Opens the list.
↑ / ↓Changes the value (closed) or moves (open).
Type a letterJumps to a matching option.

Focus

Shared ring.

Labelling

Label is the name; the placeholder option has an empty value so required works.

Contrast

Text
Border

Motion

None.

Touch

40px tall; the OS picker handles touch.

Content

  • Placeholder option is a prompt: "Choose a city".
  • Options in a meaningful order (season order, not alphabetical, for cities).

<div class="field">
  <label class="field__label" for="city">City</label>
  <select class="select" id="city" required>
    <option value="">Choose a city</option>
    <option>Toronto</option>
  </select>
</div>
