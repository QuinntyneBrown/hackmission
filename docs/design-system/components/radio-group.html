Overview

A radio group picks exactly one of a few options that should all be visible: event format, team role. Use a select when there are more than about five options.

Anatomy

  1. LegendNames the choice.
  2. Radio20px circle, accent dot when checked.
  3. Option label + description

Role and pattern

Native radios sharing a name inside a <fieldset> with a <legend>.

Keyboard

KeyAction

↑ / ↓ / ← / →Moves and selects.

Content

  • Legend is a noun: "Format", "Role".
  • One option is checked by default when a sensible default exists; otherwise none, and the legend says "required".
