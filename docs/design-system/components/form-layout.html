Form layout

How fields, groups, the summary and the actions bar sit together.

Overview

Form layout composes fields, groups, the actions bar and the error summary into one column (two for short related fields). The signup is the simplest instance: one field and one button on a row. See the forms pattern for validation timing.

Anatomy

  1. Error summaryFocused on submit; links to each field.
  2. Two-column rowOnly short related fields.
  3. Fields and groups--space-4 apart.
  4. Actions barPrimary last.

Variants

Sizes

Responsive behaviour

  • One column below 768px; the name row collapses too.
  • Actions bar: primary full width on phones, secondary beneath; one row with primary last from 640px.

Theming

No tokens of its own beyond spacing; the summary uses danger tokens.

Accessibility

Role and pattern

<form novalidate> with custom messages; fields are native. The error summary is role="alert" with tabindex="-1" and receives focus on failed submit.

Keyboard

KeyAction
TabThrough fields in DOM order (visual order).
EnterSubmits from any text field.

Focus

On failed submit focus goes to the summary; on success to the result message.

Labelling

Each summary item links to its field; the field's error is in aria-describedby.

Touch

Content

  • Summary title counts the problems: "2 things need fixing".
  • Submit label says the outcome: "Join the list", "Notify me".
  • Say what happens next on success ("Check your inbox").
