Overview

The FAQ is an accordion: each question is a <details>. The marketing page uses the plain variant (rules between items, no box); the boxed variant suits settings pages.

Anatomy

  1. SummaryExtrabold question; the button.
  2. PanelMuted answer, max 36rem.
  3. Marker+ / × from CSS.

Responsive behaviour

  • Full width of the narrow container (42rem); the question wraps, the marker stays right.

Theming

Rules use --color-border-default; answer text is muted.

Accessibility

Role and pattern

Native <details>/<summary>; the summary is a button with the expanded state built in. Multiple items may be open (FAQ); single-open uses the name attribute.

Content

  • Questions are questions ("Who can come?"); answers are one or two short sentences.
  • Six questions at most on the home page; link to a full FAQ beyond that.
