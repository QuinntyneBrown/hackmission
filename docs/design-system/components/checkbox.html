Overview

A checkbox turns one thing on or off, or picks several from a list. The signup form's consent line (CASL) is a checkbox when the form has more than the email field.

Anatomy

  1. Box20px, --radius-xs, accent when checked.
  2. LabelThe whole row is the target.
  3. Description (optional)

Variants

Interests
Single, and a group in a fieldset with a legend.

Sizes

Not applicable: One size: 20px box, 40px row.

States

VariantDefaultHoverFocusDisabledInvalid
Unchecked
Checked
Indeterminate

Responsive behaviour

  • Rows are 40px tall with the label wrapping; the box stays top-aligned.

Theming

Checked box uses --color-accent (ink in light, gold in dark) with a currentColor check mark on --color-fg-on-accent. In the hero the consent checkbox uses accent-color: var(--color-brand-gold).

Accessibility

Role and pattern

Native <input type="checkbox"> inside a <label>; groups in <fieldset> with <legend>. Indeterminate is set from script (el.indeterminate = true).

Keyboard

KeyAction
TabMoves between checkboxes.
SpaceToggles.

Focus

Shared ring around the box.

Labelling

The label text names it; the legend names the group. Required consent says so in the text, not with an asterisk.

Contrast

Check on accent
Box border

Motion

Check mark appears instantly.

Touch

The entire label row (≥ 40px) is tappable.

Content

  • Labels state the on condition: "Email me when registration opens".
  • Never phrase a checkbox negatively ("Don't email me").
