Overview

A description list pairs terms and values. The home page's numbers band (.numbers__row) is a <dl> with the value shown before the term; event detail pages use the compact horizontal form.

Anatomy

  1. Value (dd)Extrabold, gold, tabular numbers.
  2. Term (dt)Bold, large.

Responsive behaviour

  • Numbers stack vertically below 640px, three columns above.
  • Figures are fluid: clamp(3.5rem, 8vw, 6rem).

Theming

Figures use --color-brand-highlight (gold-700 on paper, gold-500 on ink).

Accessibility

Role and pattern

<dl> with div-wrapped pairs. In the numbers band the dd precedes the dt visually only; the DOM order is value then term, which reads naturally ("48 — hours").

Content
