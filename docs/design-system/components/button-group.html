Button group

Related actions in one control: a segmented single-select or a toolbar.

Overview

A button group joins related actions into one control: a segmented single-select (which view of the season to show) or a toolbar of equal actions. The marketing site has no group today; it is in the core set for the organiser tools that follow (filtering events by city or format).

Use tabs when the choice switches a whole panel of content; use a group when it changes how the same content is shown.

Anatomy

  1. Pressed segmentaria-pressed="true"; accent-subtle background.
  2. SegmentsButtons sharing one border; only the outer corners are rounded.
  3. Grouprole="group" with an aria-label naming the choice.

Variants

Segmented (single select, aria-pressed) and toolbar (independent actions, each labelled).

Sizes

Small and medium; large groups are too heavy for toolbars.

States

VariantDefaultHoverFocusDisabled
Segmented

Responsive behaviour

  • Groups never wrap; when more than four segments are needed use a select below 640px.
  • Each segment stays ≥ 32px tall and ≥ 44px wide on touch.

Theming

Reads the button tokens; the pressed segment uses --color-accent-subtle with --color-fg-accent text, which flips to a warm gold tint in dark mode.

Accessibility

Role and pattern

role="group" with aria-label; segments are native buttons with aria-pressed (segmented) or plain buttons (toolbar). APG: Toolbar for toolbars.

Keyboard

KeyAction
TabMoves through every segment (segmented) or into the toolbar.
← / →Toolbars move between buttons with arrows; segmented groups do not trap arrows.
Enter, SpacePresses the segment.

Focus

Each segment shows the shared ring; the ring sits above neighbours thanks to z-index: var(--z-raised) on focus.

Labelling

The group label names the choice ("View"); icon-only segments carry aria-label.

Contrast

Pressed label
Segment border

Motion

Same as button.

Touch

Segments ≥ 32×44px; adjacent targets share a border, so the 24px spacing rule is met by size alone.

Content

  • Segment labels are nouns naming the view: "Season", "City", "Online".
  • Two to four segments; otherwise use a select.
