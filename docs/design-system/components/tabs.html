Tabs

Switch between panels of related content without leaving the page.

Overview

Tabs switch a panel: upcoming vs past events. The marketing page uses sections and anchors instead; tabs are for the organiser tools. Use a button group when the choice only changes how the same data is shown.

Anatomy

  1. Selected tabAccent text, 2px underline.
  2. Count badge
  3. Underline track1px border under the list.

Variants

Underline tabs with a count. Pill tabs are a .btn-group.

Sizes

One size (40px); small tabs are not used.

States

VariantDefaultHoverFocusSelectedDisabled
Tab

Responsive behaviour

  • Tabs scroll horizontally with a fade when they overflow; they never wrap to two rows.
  • Labels stay short so three fit at 360px.

Theming

Selected tab uses --color-fg-accent and --color-accent underline.

Accessibility

Role and pattern

APG Tabs with automatic activation: role="tablist", tab, tabpanel, aria-selected, aria-controls; unselected tabs have tabindex="-1".

Keyboard

KeyAction
TabInto the selected tab, then into the panel.
← / →Moves and selects (automatic activation).
Home / EndFirst / last tab.

Focus

Ring on the tab; panel is focusable (tabindex="0") when it has no focusable child.

Labelling

The tablist has aria-label; counts are badges with meaning.

Unselected tab

Motion

Underline moves instantly.

Touch

Tabs 40px tall, ≥ 44px wide.

Content

  • Tab labels are short nouns: "Upcoming", "Past". No verbs.
