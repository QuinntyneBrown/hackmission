Data tables & lists

How records are listed in the organiser tools.

PatternComposes table, list, pagination, chip

Overview

No tables on the public site. Organiser tools list subscribers, events and projects; these rules keep them consistent.

When to use which

DataUse
≥ 3 comparable columnsTable
1–2 facts per recordList (two-line)
Key–value facts about one recordDescription list
> 50 recordsPagination (not infinite scroll)

Filters (chips) → table (caption, sortable header, status badges) → pagination.

States

  • Loading: skeleton rows. Empty: in-table empty state. Error: empty-state error with Try again.
  • Selection: checkbox column + bulk bar; selected rows aria-selected.

Responsive behaviour

  • Tables scroll inside their wrapper; ≤ 4 columns may become a card list below 768px.
  • Row actions always visible on touch.

Accessibility

  • Caption, header scopes, aria-sort; sort controls are buttons.
  • Pagination is a labelled nav.

Content

  • Short header nouns; dates as "15 Oct 2026"; status as a badge word.
