Pattern

Empty & error states

What to show when there is nothing, or when something broke.

PatternComposes empty-state, error-page, alert

Overview

Empties and errors are moments of trust. Each says what is true, why, and offers one way forward. The chrome stays so the person is never stranded.

When to use which

SituationComponentExample
Nothing yet (first run)Empty state, fullSeason not announced
Filters match nothingEmpty state, compact, with Clear filtersEvent list
No permissionError page 403Organiser area
Load failedEmpty state (error) with Try againVideo, schedule
Page missing / server errorError page 404 / 500Old links
Token expiredSimple page with resendConfirm link

States

  • Empty replaces only the empty region; the rest of the page stays.
  • Error-as-empty offers Try again; after three failures it offers a contact.

Responsive behaviour

  • Action full width on phones; copy caps at 36rem.

Accessibility

  • Heading level follows the page outline.
  • Error empties may be role="status"; focus is not stolen.

Content

  • Formula: what is true + why + one action.
  • No "Oops", no "No data", no blank spaces.
