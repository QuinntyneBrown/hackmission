Overview

The public site is one long page plus a few simple pages. Navigation is three anchors in the header, repeated in the footer. The organiser app will add a sidebar shell; the rules below cover both.

When to use which

NeedUse
Sections of one pageHeader anchors + <section aria-labelledby>
Separate pages (privacy)Simple/prose template with the same header and footer
Sub-views of a recordTabs
Deep hierarchy (organiser)Sidebar + breadcrumb

Skip link → header (with nav) → main with labelled sections → footer (with nav).
  • One <h1> per page; sections have h2, their items h3.
  • Anchors (#how, #season, #faq, #signup) are stable ids.
  • Back: browser back works; dialogs do not push history.

States

  • Current section link underlined (aria-current="page" on separate pages).
  • Header is not sticky; the hero takes the full first screen.

Responsive behaviour

  • Links hidden below 768px; footer repeats them.
  • Sidebar becomes a drawer below 1024px.

Accessibility

  • Landmarks: header, nav (labelled), main, footer.
  • Skip link first; headings in order; scroll-margin-top on anchor targets.

Content

  • Nav labels are section nouns; the CTA is the same verb everywhere.
