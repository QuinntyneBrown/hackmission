Layout

Breakpoints, columns, gutters, margins, the container and the page templates.

Overview

Mobile first. The base is 360px with 4 columns; 768px brings 8 columns, 1024px brings 12 and the sidebar for the organiser tools. The container caps at 1280px. The marketing page uses the container for every section and a 42rem narrow container for the FAQ and prose.

Page templates

  • Marketing (home): hero → pair → numbers → steps → statement → schedule → FAQ → footer; every section in .container.
  • Simple page (confirm, unsubscribe, 404): header → centred .simple-page (36rem) → footer.
  • Prose (privacy): header → .prose (38rem) → footer.
  • App shell (organiser, future): .sidebar-layout with topbar and sidebar.

Usage

  • Read --layout-columns/gutter/margin instead of writing media queries where you can.
  • Media queries use min-width in rem: 40rem, 48rem, 64rem.
  • Only tables and the video scroll or clip; the page never scrolls horizontally.

Accessibility

  • Reflows to 320px CSS width without two-dimensional scrolling (1.4.10).
  • Sticky elements never cover the focused element; the marketing header is not sticky.
