Color

Overview

Three brand colours do the work: ink (#0B1B3A) for text and primary actions, gold (#E8A33D) for the cross, highlights and actions on ink, paper (#F7F4EE) for the canvas. Greys, blues, greens, ambers and reds exist only for status. Light is paper with ink; dark is ink with gold actions. Every pairing a component uses is listed below with its live ratio and checked by scripts/check_contrast.py.

Usage

  • Ink on paper for everything readable; gold is an accent, never body text (gold-500 fails on paper; --color-brand-highlight is gold-700 for text).
  • On ink surfaces use the hero tokens, not the canvas ones.
  • Status colours only for status. Not for decoration, not for brand.
  • Never write a hex in a component or page; add a token.

Accessibility

  • Body text ≥ 4.5:1, large text and UI edges ≥ 3:1 (WCAG 1.4.3, 1.4.11).
  • Focus ring ≥ 3:1 against every surface it appears on, including ink (gold ring, ink gap).
  • Colour is paired with a word, an icon, an underline or a position.
