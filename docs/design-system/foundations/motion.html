Foundation

Motion

Five durations, four easings, and a reduced-motion switch in the tokens.

5 durationsReduced motion
  • Overview
  • Durations
  • Easings
  • Choreography
  • Usage
  • Accessibility
  • All motion tokens

Overview

Motion is restrained: colour changes in 120ms, reveals in 200ms, dialogs in 320ms. The hero does not animate. Under prefers-reduced-motion the tokens zero every duration, so components need no extra queries; only the spinner keeps moving, slower.

Durations

TokenUseLightDark
--duration-instant
--duration-basereveal, menus, tooltips
--duration-slowdialogs, sheets, page transitions
--duration-deliberateprogress, skeleton shimmer cycles

Easings

TokenUseLightDark
--ease-standard
--ease-exit
  • --ease-standard for colour and position changes.
  • --ease-enter for things appearing (menus, dialogs, toasts).
  • --ease-exit for things leaving.
  • --ease-spring only for the check mark in a checkbox.

Choreography

  • Hover: background/border over fast.
  • Menus and tooltips: fade + 4px rise over base.
  • Dialogs: backdrop fade and panel rise 8px over slow; sheets slide up.
  • Toasts: slide up 8px over base in; slide out over base.
  • Skeleton shimmer and indeterminate progress: deliberate, looping.

Usage

  • Animate opacity and transform only; never layout properties.
  • No animation lasts longer than 500ms; nothing loops except status indicators.

Accessibility

  • prefers-reduced-motion: reduce sets durations to 0.01ms in tokens.css.
  • No flashing; no parallax; the video never autoplays (2.2.2, 2.3.1).
