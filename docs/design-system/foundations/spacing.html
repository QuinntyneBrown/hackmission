Spacing

A 4px scale, and the rules for space inside and between things.

4px base13 steps
  • Overview
  • Scale
  • Inside vs between
  • Usage
  • Accessibility

Overview

A 4px scale from 0 to 96px. Components use ≤ --space-6 inside; layout uses ≥ --space-6 between. The marketing page is deliberately roomy: sections sit 64–136px apart.

Scale

--space-0
--space-1 4px icon-to-label
--space-2 8px inside chips, between inline items
--space-3 12px compact padding
--space-4 16px default padding, stack gap
--space-5 20px
--space-6 24px card padding, section gap (mobile)
--space-8 32px section gap
--space-10 40px
--space-12 48px page section spacing
--space-16 64px hero spacing
--space-20 80px
--space-24 96px

Inside vs between

  • Inside a control: 12px (sm), 16px (md), 24px (lg) horizontal padding.
  • Inside a card: 24px; inside a toast: 16px; inside a dialog: 24px with 16px between header, body and footer.
  • Between related controls: 8–12px; between fields: 16px; between form sections: 32px.
  • Between page sections: 64px (.section), 96px (.section--roomy, fluid to 136px on desktop).
  • Hero vertical padding: fluid 48–112px top, 64–128px bottom.

Usage

  • Never a raw pixel margin; pick the nearest step and name it.
  • Fluid spacing uses clamp() between two steps of the scale (the harvest shows 8vw, 10vw, 12vw as the fluid middle terms, always clamped to scale steps).
  • Gaps come from the parent (gap), not from children's margins.

Accessibility

  • Adjacent targets have ≥ 24px between centres or are ≥ 24px themselves (2.5.8).
  • Spacing in rem scales with the user's font size.
