Elevation

Four shadows, a surface hierarchy that works on ink, and nine layers.

4 levels9 layers

Overview

Four shadow levels and a focus shadow, a surface hierarchy (canvas < surface < raised) and nine z-layers. The marketing page is mostly flat; only the video tile (--shadow-4), toasts (--shadow-3) and the skip link rise.

In dark mode surfaces get lighter as they rise (ink-950 → ink-900 → ink-800) and shadows get darker and larger, so elevation still reads on ink.

Z-order

TokenUseLightDark
--z-base
--z-sticky
--z-overlay
--z-popover
--z-tooltip---------- Semantic: interaction ------------------------------------

A component never sets a raw z-index. Order: base < raised < sticky < dropdown < overlay (backdrop) < modal < popover < toast < tooltip.

Usage

  • Cards: shadow-1; hovered interactive cards: shadow-2; menus and toasts: shadow-3; dialogs and the video tile: shadow-4.
  • Shadows never replace borders on inputs.

Accessibility

  • Elevation is never the only cue: dialogs also have a backdrop; menus have a border.
  • --shadow-focus is the ring used where outline cannot be (hero controls).
