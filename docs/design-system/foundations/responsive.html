Overview

Mobile first; base styles target 360px. Breakpoints add space, columns and side navigation. Type steps are fixed or clamped; spacing changes by token at each breakpoint.

Touch and pointer

  • (hover: none) shows hover-only affordances permanently (row actions).
  • Targets ≥ 24px; primary mobile actions ≥ 44px (hero controls, play, dialog footer).
  • Fixed bottom elements add env(safe-area-inset-bottom); full-height layouts use 100dvh.

Testing matrix

  • 360×800, 768×1024, 1280×800, light and dark (screenshot_mocks.py).
  • Check: no horizontal scroll, no clipped text, controls ≥ 24px, dialogs become sheets, header links collapse.

Usage

  • min-width queries in rem only; prefer reading layout tokens.
  • Fluid type with clamp() between scale steps; spacing never scales with viewport width except through clamped section padding.

Accessibility

  • Reflow to 320px (1.4.10); orientation never locked (1.3.4).
