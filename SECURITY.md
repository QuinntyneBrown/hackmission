# Security Policy

## Supported versions

HackMission is in the design phase and has no released versions. Once releases begin, security fixes will be made to the latest supported release.

## Reporting a vulnerability

**Do not open a public issue for a security vulnerability.**

Use GitHub's [private vulnerability reporting](../../security/advisories/new) for this repository. Include a description, impact, reproduction steps or proof of concept, affected version or commit, and any suggested fix.

## What to expect

- We aim to acknowledge reports within 3 business days.
- We will keep you informed while we investigate and resolve the issue.
- We can credit you in release notes, with your permission, after a fix is available.

Please allow reasonable time for a fix before public disclosure.
